# Project Lazarus

A community-driven restoration project for **The Walking Dead: Destinies** (Steam, PC, App ID 2192790), built on its own custom mod loader.

**Status: early development.** Nothing here has been verified inside the running game yet. This README gets updated as pieces land and get tested; it will not claim more than has actually been checked.

## Why

The PC release shipped with almost no options (the only graphics setting is Film Grain), no key rebinding, and a handful of reported progression bugs. There is no existing modding scene or mod loader for it. Project Lazarus aims to provide one, plus fixes built on top of it.
